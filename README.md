# 智险可控 Agent（比赛演示版）

面向科技金融服务人员与人工智能科创企业的风险识别与治理演示系统。系统内置 12 家企业公开样本画像、R1—R5 风险框架、R2/R3 规则与证据库，并支持材料上传、浏览器本地解析、证据定位、尽调任务、风险减量与人工复核留痕。

## 本地运行

需要 Node.js 22 或更高版本：

```bash
npm install
npm run dev
```

构建静态网页：

```bash
npm run build
```

构建结果位于 `dist/`。

## 支持的材料

支持 PDF、DOCX、XLSX、CSV、JSON、TXT、Markdown 和图片文件。图片及旧版 Office 文件会标记为待 OCR 或待转换。单个文件建议不超过 20MB，每批最多 10 份。

## 证据边界

系统仅用于风险筛查和尽调辅助。Agent 负责材料提取、证据定位、规则匹配和任务建议；事实确认、风险定性以及授信、投资或保险决策必须由有权限的专业人员完成。
